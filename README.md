# eurojackpot-results

Eurojackpot draw results from [Eesti Loto](https://www.eestiloto.ee/tulemused?game=eurojackpot),
collected by a scheduled GitHub Action into [`data/eurojackpot_results.json`](data/eurojackpot_results.json).

Run locally (Python 3.10+, no dependencies):

```
python fetch_results.py
```
